Alarm levels

Critical

A pop-up on every page and a siren repeating every 4 seconds, until acknowledged or silenced.

Alarm

A red card in the live feed and a chime repeating every 30 seconds, until acknowledged or silenced.

Warning

An amber card in the live feed and one soft tone when it arrives.

Ignore

Not stored or shown. The event still appears in NX.

Set the level per NX rule

In the NX rule editor, type a tag in Add Title or Comment. The tag overrides everything on this page, for that rule only: #critical · #alarm · #warning · #ignore
Example: "Front gate panic button #critical", or "Truss 8 soft trigger test #warning". The portal picks up rule edits within a minute. When several rules fire for the same event, the loudest level wins.

Priority order: rule tag → Force acknowledgement (below) → event type (table below).
