Guards & vehicles (GPS)

Show where your guards and patrol vehicles are on the map, live, from the GPS in their Peplink routers. Uses your own InControl2 account: the portal reads each router's position in the background. A marker turns amber after 3 minutes without a new position and grey after 15.

seconds (15 to 600)
Getting an InControl2 Client ID and Secret
  1. Sign in at incontrol2.peplink.com with an account that can see the organization(s) with your guards' routers.
  2. Top right: your name → User Settings (or Account) → Client Application / API → New Client.
  3. Name it "TWG Alarm Portal", type Client Credentials (no redirect URL needed), and create it.
  4. Copy the Client ID and Client Secret into the boxes above, tick Track guards, Save, then Test connection.
  5. The routers need GPS turned on (in InControl2 or the router's own Location settings) and an InControl2 subscription.

Fleet vehicles (Fleetio)

Every vehicle in your Fleetio account shows on the map at its last known position in Fleetio (from your GPS / telematics integration or the Fleetio Go app). New vehicles appear by themselves; switch one off below to hide it.

seconds (30 to 3600)
Getting a Fleetio API key and Account Token
  1. Sign in at secure.fleetio.com as an admin, then open secure.fleetio.com/api_keys (Account Settings → API Keys).
  2. Add API Key, name it "TWG Alarm Portal". It only needs to read vehicles.
  3. Copy the Account Token and the API key into the boxes above, tick Show Fleetio vehicles, Save, then Test connection.
  4. Vehicles get positions in Fleetio from a GPS / telematics integration (or Fleetio Go). The test shows how fresh they are.

Fleet vehicles (Geotab · ZenduONE · GoFleet)

Every active vehicle in your Geotab (MyGeotab) database shows on the map at its last position from its GO device, with speed. ZenduONE and GoFleet run on Geotab. New vehicles appear by themselves; switch one off below to hide it.

Leave blank unless told otherwise
seconds (30 to 3600)
Getting a Geotab login for the portal
  1. Sign in to MyGeotab as an administrator. The database name is the part after my.geotab.com/ in the address bar. ZenduONE / GoFleet customers without MyGeotab access: ask ZenduIT (servicedesk@zenduit.com) for a service account for your database.
  2. Administration → Users → Add: a user just for the portal (e.g. service-alarmportal@yourcompany.com), basic authentication, a strong password.
  3. Data access: the groups holding the vehicles to show. Security clearance: one that can view vehicles and their location; the portal only reads.
  4. Type the database, user name and password above, tick Show Geotab vehicles, Save, then Test connection.
  5. If Geotab refuses the login, the portal waits 10 minutes before trying again (so it never locks the user); saving again tries at once.

Add a guard without a router (phone)
