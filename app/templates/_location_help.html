Location blocked? How to allow it

iPhone (Safari)

  1. Open Settings → Privacy & Security → Location Services: make sure it's On.
  2. In that list, tap Safari Websites → choose While Using the App (or Ask Next Time). If it says Never, no website can ask.
  3. Back in Safari, tap aA (left of the address) → Website Settings → Location → Allow (or Ask).
  4. Reload this page and tap the button again. Tap Allow when Safari asks.

Android (Chrome): tap the icon left of the address → Permissions → Location → Allow, then reload. Location must be on in the phone's quick settings.
