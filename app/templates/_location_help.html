Location blocked? How to allow it

iPhone (Safari)

  1. Open Settings → Privacy & Security → Location Services: make sure it's On.
  2. In that list, tap Safari Websites → choose While Using the App. If it says Never, no website can ask. (Also turn on Precise Location there for an exact position.)
  3. Back in Safari, tap aA (left of the address) → Website Settings → Location → Allow. That also stops Safari asking every time.
  4. Reload this page and tap the button again.

If you tapped Don't Allow once, Safari keeps refusing this site until you change step 3.

Android (Chrome): tap the icon left of the address → Permissions → Location → Allow, then reload. Location must be on in the phone's quick settings.
